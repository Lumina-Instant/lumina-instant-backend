# Lumina Instant Messaging Platform – Backend Repository

This repository contains the Node.js backend infrastructure for the Lumina messaging platform. It handles user authentication, RESTful API requests, real-time WebSocket communication, and database management.

## 🚀 Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Real-Time Engine:** Socket.io
* **Primary Database:** PostgreSQL
* **In-Memory Cache:** Redis (for session management and online status)
* **Containerization:** Docker & Docker Compose

## 🛠 Prerequisites
* [Node.js](https://nodejs.org/en/download/) (v18.x or higher)
* [Docker & Docker Compose](https://www.docker.com/products/docker-desktop) (for running local database instances)
* Git
